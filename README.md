# AI Stack — Claude Skill voor AI FiT Leiderschap

Een Claude Skill die Claude leert werken met de **AI Stack**: het model van Salim Ismail uit ExO 3.0 (*The Organizational Singularity*, OpenExO 2026), in de bron de *Intelligence Stack*. De organisatie als cyclus die nooit stopt:

PURPOSE → SENSE → INTERPRET → DECIDE → ORCHESTRATE → LEARN, met GOVERN eronder.

In week 4 van AI FiT Leiderschap bouw je hiermee je eigen AI Stack, laag voor laag, op basis van je `MIJN-CANVAS.md`.

## Installeren

1. Download **[exo-intelligence-stack.zip](https://github.com/hpamike/exo-intelligence-stack/releases/latest/download/exo-intelligence-stack.zip)**. Niet uitpakken.
2. Open Claude → **Customize → Skills → Add** en kies de ZIP.
3. Zet de skill aan als er een schakelaar bij staat.
4. Begin een **nieuw gesprek** en test met: *"Wat zijn de lagen van de AI Stack?"*

Let op: gebruik de ZIP hierboven, niet de groene knop "Code → Download ZIP". Die zet er een extra map omheen, en dan weigert Claude de upload.

## Inhoud

- `SKILL.md` — instructies, met taak C: bouwen per laag
- `references/` — de theorie, REWRITE en een uitgewerkt voorbeeld (VECTOR / AI FiT)
- `assets/analyse-template.md` — de invulstructuur

Bron van het model: Salim Ismail, [*The Organizational Singularity*](https://openexo.com/organizational-singularity), OpenExO. Deze skill is een Nederlandstalige werkversie voor AI FiT Leiderschap.
